
# Essential Stories
1. As a player I want to be able to select difficulty and see the corresponding 2d maze.
2. As a player I want to be able to move my character from point x to point y.
3. As a developer I want the game to give a warning when handling invalid inputs like walking in to a wall.
4. As a developer I want the game to end when the time runs out.
5. As a player I want to be able to see and interact with the current state of the game.

# Optional Stories
1. As a developer I only want the explored part of the maze to be visible.
2. As a player I want to receive hints for points of interest outside of my vision.
3. As a developer I want to generate traversable randomized mazes.
4. As a player I want items to help complete the game (pickaxe, extra time, keys or maps)
